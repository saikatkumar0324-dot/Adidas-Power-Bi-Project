# Adidas Sales Analysis – Power BI Dashboard

An interactive Power BI dashboard that analyzes Adidas sales performance across time, regions, products, and retailers (Jan 2020 – Dec 2021).

![Adidas Sales Dashboard](images/dashboard.png)

## Key Metrics

| Metric | Value |
|---|---|
| Total Sales | $899.9M |
| Total Profit | $332.1M |
| Units Sold | 2.5M |
| Avg Price per Unit | $363.0 |
| Avg Margin | 42.3% |

## Key Insights

- **Seasonality:** Sales peak in the summer months (July ≈ $95M, August ≈ $92M) and are lowest in March (≈ $57M).
- **Top retailers:** West Gear ($243M) and Foot Locker ($220M) generate the most sales, followed by Sports Direct ($182M).
- **Top products:** Men's Street Footwear leads with $208.8M, followed by Women's Apparel ($179.0M) and Men's Athletic Footwear ($153.7M).
- **Regional split:** The strongest region brings in about $270M in sales, with the other regions between roughly $136M and $186M.

## Dashboard Features

- KPI cards for sales, profit, units sold, average price, and margin
- Monthly sales trend (area chart)
- Map of sales by state
- Sales by region (donut chart), product (bar chart), and retailer (bar chart)
- Date range slider and region slicer with a **Clear** button for filtering

## Tools Used

- Power BI Desktop
- DAX measures
- Power Query (data cleaning and transformation)

## How to Open

1. Download `Adidas_power_bi_dashboard_by_sk.pbix` from this repository.
2. Open it with [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (free).
